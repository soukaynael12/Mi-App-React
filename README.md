# React To-Do List App

This is my first React project! A fully functional To-Do List application built with React Hooks.

## 🚀 Features
- **Add tasks:** Type in the input and click "Add".
- **Delete tasks:** Click the red "X" button to remove a task.
- **Persistent Data:** Uses `useEffect` and `localStorage` to save tasks in the browser, so they don't disappear when you reload the page.

## 🛠️ Technologies Used
- React
- JavaScript (ES6+)
- HTML & CSS
- Vite

## 🧠 What I learned
- How to use `useState` to manage the input and the task list.
- How to use `useEffect` to sync data with `localStorage`.
- How to map through an array to render list items.
